# Task 3 – SQL Analysis on Classic Models Database

## 📌 Objective
Perform SQL-based data analysis using the `classicmodels` sample database, demonstrating use of filtering, joins, grouping, subqueries, and views.

## ✅ Concepts Covered
- SELECT, WHERE, ORDER BY
- GROUP BY and Aggregations
- INNER JOIN and LEFT JOIN
- Subqueries
- View Creation

| Query | Description |
|-------|-------------|
| q1    | Customers from USA (SELECT, WHERE, ORDER BY) |
